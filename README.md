## Introduction

This project is developed as part of the coursework for **CSW 304**.

The objective is to apply frontend web development knowledge to design and build a webpage interface using HTML, CSS, and related technologies.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
- Google Font

## Features

- Responsive webpage layout
- Navigation bar and header
- Custom styling and layout design

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/phamnguyenminhquan/kid-kinder.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
